# UI signature: transaction trace lab

Status: current.

The dashboard behaves like a forensic clearing desk: a pale cool work surface held inside deep-ink navigation chrome, with a single ultraviolet trace color following one payment through provider, inbox, ledger, settlement, and payout. Hairline coordinate rules and square-ish “evidence panes” replace floating cards. Status colors are limited to verified teal, held amber, and failed coral.

Numerals use a tabular monospace face. The signature visualization is the `TraceRail`: one continuous lifecycle line whose checkpoints expose the exact boundary crossed and timestamp. KPI values form one divided `BalanceStrip`. Empty states describe the next financial event that will appear; loading skeletons preserve the evidence-pane geometry. Motion is limited to the active checkpoint trace and is disabled under `prefers-reduced-motion`.

This language is intentionally neither a banking-marketing page nor a generic analytics dashboard: its visual structure exists to teach event causality.
